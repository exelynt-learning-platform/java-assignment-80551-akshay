## 4. Connect the Local Repository to GitHub

Open your Mac Terminal and navigate to the existing project:

```
cd GitBasics
```

Check the current branch:

```
git branch
```

If your current branch is not `main`, and you want to use `main` for this assignment, run:

```
git branch -M main
```

Now copy the HTTPS repository URL from your newly created GitHub repository. It will look similar to:

`https://github.com/YOUR-USERNAME/GitBasics.git`

Replace `YOUR-USERNAME` with your actual GitHub username.

Add the remote repository:

```
git remote add origin https://github.com/YOUR-USERNAME/GitBasics.git
```

Verify the connection:

```
git remote -v
```

Expected output format:

```
origin  https://github.com/YOUR-USERNAME/GitBasics.git (fetch)
origin  https://github.com/YOUR-USERNAME/GitBasics.git (push)
```

Here, `origin` is the conventional name for the remote repository.&#x20;

## 5. Push Your Local Repository to GitHub

First, confirm that your local changes have been committed:

```
git status
git log --oneline
```

Then upload your commits to GitHub:

```
git push -u origin main
```

You may need to authenticate through your browser or a configured Git credential method.

Explanation:

- `git push` uploads local commits to the remote repository.
- `origin` identifies the remote repository.
- `main` identifies the branch being uploaded.
- `-u` sets the upstream tracking relationship for future pushes and pulls.

These steps follow GitHub's documented process for publishing an existing local repository.&#x20;

## 6. Verify the Repository on GitHub

1. Open your repository page on GitHub.
2. Refresh the page.
3. Confirm that `index.txt`, `about.txt`, and any other committed files are visible.
4. Open the commit history to verify that your commits have been uploaded.

If the files appear on GitHub, the local-to-remote connection and push have worked.
